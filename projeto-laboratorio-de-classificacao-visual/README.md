# 📝 Descrição do Projeto

O **SmartVision Classifier** é um sistema de classificação de imagens desenvolvido com a plataforma **Google Teachable Machine**, utilizando técnicas de **Machine Learning** e **Visão Computacional** para realizar reconhecimento visual em tempo real através da webcam.

O projeto foi criado com foco em aprendizado prático de Inteligência Artificial supervisionada, permitindo o treinamento de diferentes categorias de imagens sem necessidade de programação avançada ou configuração manual de redes neurais.

O modelo foi exportado em **TensorFlow.js**, possibilitando execução diretamente no navegador com processamento local e baixa latência.

# 🧠 Funcionamento do Modelo

O sistema utiliza **Transfer Learning**, técnica que aproveita redes neurais previamente treinadas para acelerar o aprendizado de novas classificações.

O modelo foi treinado utilizando imagens separadas em categorias específicas, permitindo que a IA reconheça padrões visuais e realize previsões probabilísticas em tempo real.

### Características Técnicas

* **Input de imagem:** 224x224 pixels
* **Framework:** TensorFlow.js
* **Execução Local:** Browser-based AI
* **Classificação:** Multiclasse
* **Inferência em tempo real**
* **Predição percentual por categoria**

# 🧪 Pipeline de Funcionamento

O sistema realiza:

1. Captura da imagem via webcam.
2. Pré-processamento automático da imagem.
3. Envio para o modelo treinado no Teachable Machine.
4. Inferência utilizando TensorFlow.js.
5. Exibição das probabilidades de classificação.
